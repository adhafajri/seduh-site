A proposed, tested migration kit for indie iOS developers who need to evolve a live SwiftData store safely.

Proposed launch price: US$19. This page measures whether the kit is worth building. The button below records interest only; it does not charge you or collect personal information.

The failure this addresses

Recent public iOS projects are still reporting stores that crash after an upgrade, staged migrations that cannot identify an older model version, migrations that never run, and recovery code that silently deletes local history. A clean install does not expose these failures; an old production store does.

Planned contents

  • A minimal Swift project with V1, V2, and V3 VersionedSchema examples.
  • Old-store fixtures that prove each migration path against real persisted data.
  • Swift Testing checks for values, relationships, defaults, and destructive regressions.
  • A non-destructive recovery flow: diagnose, export when possible, and explain before reset.
  • A release checklist covering backups, downgrade behavior, CloudKit considerations, and rollback evidence.
  • Plain documentation explaining what the sample proves and what still needs app-specific testing.

What it will not claim

  • No promise that one sample covers every schema or CloudKit configuration.
  • No fabricated “production-safe” guarantee without tests against your own store.
  • No subscription, hidden fee, or financial product.
