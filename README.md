# Seduh — panduan seduh kopi di rumah

Seduh adalah situs panduan kopi berbahasa Indonesia untuk pemula. Isinya membantu
pembaca menentukan takaran kopi dan air, mempelajari V60, dan memilih alat dasar
tanpa istilah rumit atau dorongan membeli alat yang tidak perlu.
